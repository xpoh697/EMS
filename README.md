A smart, algorithmic Energy Management System integration for Home Assistant designed to maximize solar consumption and power efficiency.

## Features (Basic Version)
- **Menu-based Settings Flow**: Configured easily via Home Assistant options flow category menus.
- **Sensor Integration**: Requests and tracks:
  - Total load consumption sensor.
  - PV Forecast today.
  - PV Forecast tomorrow.

## Installation
1. Install via HACS (add as custom repository: `https://github.com/xpoh697/EMS`).
2. Restart Home Assistant.
3. Configure the integration via Settings -> Devices & Services.
