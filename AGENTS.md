# Project Rules — EMS

## Testing
- После любых изменений в коде (`custom_components/ems/**`, `tests/**`, скрипты деплоя/утилиты) обязательно запускай тесты командой:
  `pytest tests/`
- Не запускай тесты, если изменялись только файлы документации (`*.md`).
- Запрещено считать задачу завершённой или ослаблять проверки/ассерты, если тесты падают.
- Запрещено выполнять деплой (`deploy.ps1` или синхронизацию в `\\192.168.100.5\config\custom_components\ems`), пока `pytest tests/` не завершится с кодом `0`.
